UsersTable

class UsersTable

Resolves the application's users table for the package migrations.

The package extends the application's users table, it does not own it. This helper resolves the table from the configured User model, asserts that the application has created it, and mirrors its primary key definition so that foreign keys pointing at it are always type compatible.
